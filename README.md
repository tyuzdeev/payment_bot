Telegram Digital Shop Bot (with Native Payments API)
Бот для автоматизированной продажи цифровых товаров и премиум-доступов.

Фичи:

Интеграция нативной оплаты Telegram (Stripe/ЮKassa).

Двухэтапная валидация транзакции (pre_checkout_query), предотвращающая ошибки списания средств при сбоях БД.

Защита от поддельных Payload-инвойсов.

Генерация динамической витрины через Inline-клавиатуры (готовность к подключению БД).

Как получить PAYMENT_TOKEN для тестов (бесплатно и без реальных денег):
Идешь в @BotFather, пишешь /mybots, выбираешь своего бота.

Жмешь Payments.

Выбираешь, например, YooKassa или Stripe -> выбираешь Test (Тестовый режим).

BotFather выдаст длинный токен оплат с припиской TEST. Копируешь его в свой .env.

Теперь ты можешь "покупать" товары у своего бота тестовыми картами (например, номер карты 1111 1111 1111 1026, до 12/26, CVC 000). Реальные деньги не спишутся.
